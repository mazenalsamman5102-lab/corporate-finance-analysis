# Corporate Finance Analysis

**Capital Budgeting, Company Valuation & Working Capital Analysis**

## Project Overview
An academic group project completed as part of an Advanced Corporate Finance course using Microsoft Excel.

## Key Analyses

### 1. Capital Budgeting
- Evaluated investment projects using NPV, IRR, MIRR, Profitability Index, and Payback Period.

### 2. Company Valuation
- Analyzed and valued Saudi-listed companies using financial statements and free cash flow analysis.

### 3. Working Capital Analysis
- Assessed working capital efficiency, inventory turnover, and cash conversion cycles.

## Tools
- Microsoft Excel
- Financial Analysis
- Financial Modeling
